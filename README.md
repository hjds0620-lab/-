# MATLAB 응용수학 수업 자료

MATLAB을 활용한 응용수학 및 수치해석 수업 예제입니다. 기본 문법부터 유한차분법을 이용한 2차원·3차원 확산방정식의 계산과 시각화까지 다룹니다.

## 수업 자료

| 파일 | 내용 |
|---|---|
| `hj_0902.m` | MATLAB 기본 연산, 벡터 비교, 조건문, 반복문, 행렬 생성 및 그래프 |
| `hj_0908.m` | 전진차분법과 중앙차분법을 이용한 미분 근사 및 오차 비교 |
| `hj_0915.m` | 2차원 확산방정식의 명시적 유한차분 해법 |
| `hj_0916.m` | 3차원 확산방정식, Neumann 경계조건, 등가면 및 에너지 시각화 |

## 실행 방법

1. MATLAB에서 저장소 폴더를 엽니다.
2. 실행하려는 `.m` 파일을 엽니다.
3. **Run** 버튼을 누르거나 명령 창에 확장자를 제외한 파일명을 입력합니다.

예:

```matlab
hj_0915
```

## 주요 수학 모델

확산방정식

```text
∂φ/∂t = ∇²φ
```

을 유한차분법으로 이산화하여 시간에 따른 해의 변화를 계산합니다. 2차원 및 3차원 예제에서는 경계면의 법선 방향 미분을 0으로 두는 Neumann 경계조건을 사용합니다.

## 참고

- `hj_0915.m`과 `hj_0916.m`은 반복 계산 중 그래프를 갱신합니다.
- `hj_0916.m`에서는 **정지** 버튼 또는 에너지 기준값을 이용해 계산을 종료할 수 있습니다.
- 실행 시간은 컴퓨터 환경과 MATLAB 버전에 따라 달라질 수 있습니다.
